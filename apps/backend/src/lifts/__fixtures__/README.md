# Testdaten LiftRadar

Frei erfundene Gebiete (Testberg, Musteralp, Stillhang, Neuegg, Grenzberg) im Aufbau
der echten Antworten von https://liftradar.eu/api (geprüft am 25.11.2026):
`index.json`, `<id>.json` und `<id>.details.json`. Enthält bewusst Sonderfälle:
ein ungültiger Index-Eintrag, ein unbekannter Statuswert («wartung»), ein
`javascript:`-Link, ein Gebiet ohne Bericht («no_report») und eines ohne Pistenzahlen.
